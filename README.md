# Витрина туристских поездов

Тестовое задание для Центра развития туризма АО «ФПК»: одностраничный каталог пяти туристских поездов с поиском, фильтрами и подробной карточкой маршрута.

Демо: [https://neroznak.github.io/rzhd-test-task/](https://neroznak.github.io/rzhd-test-task/)

## Локальный запуск
Требования: Node.js 20.9+ и npm. Выполните `npm ci`, затем `npm run dev` и откройте [http://localhost:3000](http://localhost:3000).
Проверка перед публикацией: `npm run lint` и `npm run build`.

## Использованный стек и решения
Next.js 16 (App Router), React 19, TypeScript и Tailwind CSS 4; код организован по FSD для разделения данных, бизнес-логики и интерфейса.
Исходный `trains.json` импортируется без изменения и проходит runtime-валидацию; компоненты по умолчанию серверные, а `use client` используется только для фильтров и диалога.
Интерфейс адаптирует визуальный язык РЖД: сдержанная палитра, крупный поиск, адаптивные карточки и доступное модальное окно с управлением фокусом и клавиатурой. Корпоративный шрифт использован только в этом учебном прототипе и не означает официального применения фирменного стиля.
Статический экспорт публикуется на GitHub Pages из ветки `main`.
Если маршрутов больше 10, каталог показывает их порциями по кнопке «Показать ещё», чтобы не выгружать весь список сразу.
